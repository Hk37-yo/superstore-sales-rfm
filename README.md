# AI-Assisted Sales Analysis & RFM Customer Segmentation

## 📌 Project Overview
This project focus on a comprehensive commercial audit of a retail business. The goal was to analyze revenue across different product categories, identify strong and weak regional segments, and perform an advanced RFM (Recency, Frequency, Monetary) customer segmentation to help optimize marketing strategies and increase business ROI.

## 🛠 Tech Stack
* **SQL** (Data extraction, aggregation, grouping, and filtering using complex query logic)
* **Python / Google Colab** (Pandas for data manipulation, Matplotlib for building revenue charts)
* **MS Excel** (Initial data profiling and structure verification)
* **Prompt Engineering (LLM)** (Leveraging modern AI assistants for rapid code generation, debugging, and code review)

## 🎯 Key Features Implemented:
1. **SQL Data Extraction:** Designed and executed SQL queries (`SELECT`, `GROUP BY`, `ORDER BY`, aggregate functions) to extract clean sales metrics from the database.
2. **AI-Assisted Workflow (Pandas):** Efficiently utilized LLM models to generate and debug Python scripts. Acted as a Code Reviewer to validate backend logic and ensure mathematical accuracy.
3. **Data Visualization:** Built clean bar charts using Matplotlib to represent revenue distribution across product categories for business stakeholders.
4. **Advanced Marketing Analytics (RFM):** Segmented the entire customer base into actionable cohorts based on Recency, Frequency, and Monetary values. Exported the results into a final, production-ready dataset: `rfm_segments.csv`.

## 💼 Business Value
The resulting dataset (`rfm_segments.csv`) allows the marketing team to target specific customer groups (e.g., re-engaging churning users or rewarding loyal customers), preventing budget waste and directly improving business revenue.
